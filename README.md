# PocketOS
## PocketOS is an Operating System and graphical Interface for ESP32 Display boards, featuring support for many peripherials and an own Network to, for Example, send and recieve messages.
***
## Installation
### Dependencies
- Arduino IDE 2.0 or higher
- Firebeetle ESP32-E Board Support Package
- Partition Sheme: Huge APP (3MB APP / ?? MB SPIFFS)
- 4 inch ESP32-32E Display Board
- MicroSD/TF Card (at least 1GB)
